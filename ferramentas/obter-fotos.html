Obter as fotografias do portal

As fotografias da lista do Município, prontas a guardar já com o nome certo. Esta página corre no seu computador — não precisa de servidor nem de instalar nada.

  1. Clique em Guardar num cartão. O navegador descarrega a fotografia.
  2. Se o navegador lhe der outro nome, use o que está no cartão — por exemplo visitar/patrimonio.jpg significa o ficheiro patrimonio.jpg dentro da pasta public/images/visitar/.
  3. Copie os ficheiros para public/images/ do portal, respeitando as pastas.
  4. Volte a compilar (npm run build). O portal passa a mostrar as fotografias.

Tem terminal? Então é mais rápido: npm run fotos faz tudo isto de uma vez.

Antes de publicar: confirme junto do Município os direitos de utilização de cada fotografia. As que vêm do próprio sítio municipal são as mais seguras; as de blogues, sítios de reservas e da Wikimedia precisam de autorização ou de atribuição.

Se um cartão aparecer vazio, o sítio de origem deixou de servir a imagem ou bloqueia ligações de fora. Use o botão Abrir para a ver no sítio original e guardá-la manualmente.
